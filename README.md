# C-Bowling-Score-Calculator
A bowling score calculator written in C, using a python tkinter GUI to input the scores.

# How to run
The .exe file is already included so just running the python file should be all that is needed, the C is written in Ansi C, so the compilation needs to specify that if you want to compile it yourself. The python file compiles it for you when you run it as long as you have GCC on your system.
